# Battlechan — Solana SocialFi

Social network built on Solana blockchain.

## Features
- Time-based posts
- Upvote/downvote with tokens (AI vs Human verified)
- Privy authentication + ZK Compression
- Session keys + PDA threads
- Token-2022 tax

## Stack
- Frontend: Next.js
- Mobile: React Native
- Blockchain: Solana (Privy, ZK Compression, Token-2022)
- Feed: 100-topic scraper
